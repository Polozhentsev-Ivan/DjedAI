# Тесты

- `unit/` — отдельные компоненты и детерминированная логика.
- `integration/` — взаимодействие с API, БД, хранилищем и событиями.
- `e2e/` — сквозные пользовательские сценарии.
- `fixtures/` — небольшие общие тестовые данные.

Правила и порог покрытия находятся в [CONTRIBUTING.md](../CONTRIBUTING.md). Маркеры pytest `integration` и `llm` управляют выбором прогона и зарегистрированы в `pyproject.toml`. Команды отдельных интеграционных проверок находятся в [integration/README.md](integration/README.md).
