# Тесты

- `unit/` — отдельные компоненты и детерминированная логика.
- `integration/` — взаимодействие с API, БД, хранилищем и событиями.
- `e2e/` — сквозные пользовательские сценарии.
- `fixtures/` — небольшие общие тестовые данные.

Правила и порог покрытия находятся в [CONTRIBUTING.md](../CONTRIBUTING.md). Папка задаёт расположение тестов, а маркеры pytest `integration` и `llm` управляют выбором прогона; маркеры и конфигурацию добавим вместе с окружением.

Тесты и инструменты пока не созданы. Пустой каталог не считается пройденным тестированием.
