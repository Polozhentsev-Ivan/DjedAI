# Unit-тесты

Проверки отдельной логики: преобразований, валидации, вычислений, состояния агента и форматирования. Имена Python-файлов — `test_*.py`.

Набор не требует GPU, реальной модели или внешней сети. Вызовы внешних компонентов заменяем управляемыми ответами; проверяем содержательный результат и важные ошибки, а не внутреннее устройство функции.
