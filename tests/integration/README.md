# Интеграционные тесты

Проверки реального взаимодействия: DuckDB, адаптеры БД, миграции, API, хранилище, SSE и совместимость контрактов.

Используем отдельные тестовые данные и БД. Для запуска описываем сервисы и конфигурацию; тесты помечаем `integration`, а требующие реальной модели — дополнительно `llm`. Фактическая инфраструктура тестирования появится вместе с реализацией.
