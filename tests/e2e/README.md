# Сквозные проверки

Пользовательские сценарии от регистрации и источника данных до вопроса, сохранённого результата, графика или обновления дашборда. Здесь же место проверкам двух пользователей через несколько компонентов.

Для каждого прогона указываем сборку, окружение и шаги воспроизведения. Сквозным тестам, требующим сервисов, ставим маркер `integration`, а при реальной модели — `llm`; отдельного нового набора маркеров каркас не вводит.
