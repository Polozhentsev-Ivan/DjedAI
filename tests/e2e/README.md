# Сквозные проверки

Пользовательские сценарии от регистрации и источника данных до вопроса, сохранённого результата, графика или обновления дашборда. Здесь же место проверкам двух пользователей через несколько компонентов.

Для каждого прогона указываем сборку, окружение и шаги воспроизведения. Python-тестам, требующим сервисов, ставим маркер `integration`, а при реальной модели — `llm`. Браузерные проверки React-интерфейса будут выполняться Playwright; runner, команды и окружение появятся с frontend-каркасом в B4-1 / #83. Маркеры pytest к браузерным тестам не относятся. До реализации соответствующих scripts и CI такие прогоны не считаются выполненными.
