# Оценка агента

Эталонные вопросы и ожидаемые инструменты, факты, значения и реакции на некорректные запросы. По согласованному плану здесь появится `questions.yaml` и результаты работы прогонщика в предусмотренном формате.

Эталоны и код воспроизводимого прогона храним в Git; сгенерированные отчёты — в локальном `artifacts/`. Контрольный набор расширяется до минимум 52 вопросов по критериям issues.

Оценка реальной модели дополняет unit/integration-тесты; она не заменяет независимую проверку вычислений. Пока нет вопросов и реализации, пустой YAML не создаём.
