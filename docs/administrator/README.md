# Установка и эксплуатация

Для человека, который устанавливает DjedAI, настраивает модель и источники, обновляет приложение и отвечает за сохранность данных. Понадобятся доступ к машине установки и базовые навыки работы с терминалом и Docker.

## Первая установка

Начните с [локальной сборки и запуска](local-build.md): требования, получение исходников, конфигурация, запуск Compose и проверка готовности. Контрольный пользовательский сценарий в этой главе нужен для приёмки установленного приложения.

## Настройка

[Конфигурация](../configuration.md) описывает адрес и ключ модели, разрешённые модели, подключение баз, шифрование, передачу данных, ограничения нагрузки и диагностические параметры.

Перед выдачей доступа пользователям определите модель и допустимый состав передаваемых ей данных, сохраните ключ шифрования и проверьте доступность нужных источников.

## Повседневная эксплуатация

[Эксплуатация и восстановление](operations.md) содержит команды запуска/остановки, диагностику, работу с диском и очередями, обновление, резервное копирование и восстановление.

Это процедуры для текущей поставки с одной backend-репликой и постоянным томом. Инструкция восстановления должна быть проверена на отдельной копии вашей установки.
