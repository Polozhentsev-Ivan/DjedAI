# «Как посчитано» и «В дашборд» — B4-6 / #88

Пользователь видит, откуда взялось число в ответе, и сохраняет график ответа в
личный дашборд. Backend для этого уже есть: реестр результатов (#96) и Dashboard
API с рецептами (#97, [описание](97-dashboard-api-refresh.md)). Задача #88
подключает их в чате.

## «Как посчитано»

`HowCalculated` (`frontend/src/components/HowCalculated.tsx`) показывает:

| Строка | Откуда |
|---|---|
| Инструмент | `ToolResult.tool` |
| Параметры | `ToolResult.params`, по одному на строку; `source_result_id` сюда не попадает |
| Рецепт | только у виджета дашборда: `tool_call` или шаги `recipe`, которые повторяет обновление |
| Источник результата | `ToolResult.source_result_id`, ссылка на `GET /api/results/{id}` |
| Колонки, Обработано | `ToolResult.data` |
| Данные | `ToolResult.read`: режим чтения, время и ревизия каталога |
| Ограничения | `ToolResult.quality` и свежесть каталога |
| SQL | `ToolResult.sql` |

Все сведения берутся из сохранённого результата через `calculation()`
(`frontend/src/api/view.ts`), а не восстанавливаются по графику или тексту ответа.
На графике чата (`ChartAnswer`) метаданные читаются только при раскрытии панели.

## «В дашборд»

`SaveToDashboard` (`frontend/src/components/SaveToDashboard.tsx`) стоит в
заголовке каждого графика ответа, если известен датасет чата.

- Меню при открытии читает `GET /api/dashboards?dataset_id=…` и предлагает
  дашборды этого датасета и «Новый дашборд».
- `POST /api/dashboards` получает только `dataset_id`, `result_id`, `chart` и,
  для существующего дашборда, `dashboard_id`. Рецепт клиент не строит: сервер
  восстанавливает его по цепочке `source_result_id`, проверяет владельца и
  отклоняет чужое (404) или неполную цепочку (422).
- Название нового дашборда сервер берёт из заголовка графика.
- После сохранения над полем ввода на 6 секунд появляется уведомление со ссылкой
  на дашборд. Ошибка сохранения выводится под кнопкой, повтор — тем же меню.

Повторное открытие идёт через обычный `GET /api/dashboards/{id}`, поэтому виджет и
рецепт показываются такими, какими их сохранил сервер.
