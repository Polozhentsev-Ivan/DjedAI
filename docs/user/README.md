# Пользователю

Для аналитика или другого человека, который работает с данными в браузере. Предполагается, что DjedAI уже установлен и вам известен его адрес.

**[Открыть руководство пользователя](user-guide.md)**

В руководстве: первый анализ, загрузка файлов и подключение базы, проверка каталога, вопросы в чате, чтение результатов, графики, дашборды и решение обычных проблем.

Начните с небольшого CSV-примера: он позволяет пройти весь сценарий и проверить ответ вручную.
