# Руководство пользователя DjedAI

DjedAI помогает анализировать таблицы через вопросы на обычном языке. Вы добавляете данные, проверяете их описание и спрашиваете о показателях. Ответ может содержать пояснение, таблицу, график или дашборд.

Для работы понадобятся адрес приложения и данные для анализа. Адрес выдаёт человек, который установил DjedAI. Это руководство описывает работу в браузере; программирование для описанных действий не требуется.

## Первый анализ на небольшом примере

Попробуйте начать с файла, для которого легко проверить ответ.

1. Создайте текстовый файл `mini_sales.csv` в кодировке UTF-8 и скопируйте в него:

   ```csv
   id,sale_date,region,amount
   1,2026-10-01,North,12
   2,2026-10-02,South,30
   3,2026-10-03,North,8
   ```

2. Откройте DjedAI и зарегистрируйтесь либо войдите.
3. Перейдите в **Источники → Загрузить CSV**, нажмите **Обзор** и выберите файл.
4. Дождитесь статуса **Готов** и нажмите **Посмотреть каталог**.
5. Убедитесь, что в таблице три строки, а колонка `amount` распознана как числовая.
6. Нажмите **Задать вопрос в чате** и отправьте:

   > Сколько строк в таблице и какова сумма amount?

7. Раскройте **Результат расчёта …** под ответом. Ожидаются **3 строки** и **сумма 50**.

Продолжите в том же чате:

> Покажи сумму amount по region столбчатой диаграммой.

Ожидаемые значения: `North` — **20**, `South` — **30**. В примере не указана валюта, поэтому эти суммы следует читать как обычные числа.

Если система просит уточнить таблицу или колонку, выберите подходящий вариант. Формулировка ответа может отличаться, но результат вычисления должен совпасть с числами выше.

## Вход и рабочее пространство

Для регистрации выберите **Регистрация**, задайте **Имя пользователя** и **Пароль**, затем нажмите **Зарегистрироваться**. После успешной регистрации приложение открывает рабочее пространство. Если имя занято, выберите другое либо войдите в существующий аккаунт.

При следующем входе используйте имя пользователя и пароль. Если приложение сообщает, что сессия истекла, войдите снова. Кнопка **Выйти** расположена справа вверху. Выход сохраняет ваши датасеты, чаты и дашборды: они появятся после нового входа в тот же аккаунт. Восстановление пароля через интерфейс пока недоступно; обратитесь к администратору.

Основные разделы находятся слева:

| Раздел | Для чего нужен |
| --- | --- |
| **Источники** | Добавить данные и выбрать готовый набор |
| **Каталог** | Посмотреть таблицы, колонки и замечания к данным |
| **Чат** | Задавать вопросы и возвращаться к прошлым разговорам |
| **Дашборды** | Открывать сохранённые подборки показателей и графиков |
| **Настройки** | Выбирать доступную модель |

Список **Активный датасет** сверху определяет, с каким набором вы работаете. Датасет может содержать одну таблицу или несколько связанных таблиц. При открытии сохранённого чата или дашборда автоматически выбирается его набор данных.

Значок солнца или луны переключает тему оформления. На узком экране боковая панель может показывать только значки; их названия видны при наведении.

## Добавление данных

### CSV-файлы

Откройте **Источники → Загрузить CSV**. Выберите файлы через **Обзор** либо перетащите их в область загрузки. Несколько файлов, отправленных вместе, станут таблицами одного датасета.

Поддерживаются CSV с разделителем запятой, точкой с запятой или табуляцией, в кодировках UTF-8 и CP1251. Для первого знакомства удобны понятные заголовки, явные числовые значения и даты вида `2026-10-01`. Файл Excel сначала сохраните в формате CSV.

Дождитесь статуса **Готов**, затем откройте **Посмотреть каталог**. Во время обработки можно перейти в другой раздел. **Скрыть прогресс** закрывает панель наблюдения, а уже принятая обработка продолжается. Вернуться к ней можно через **Следить за обработкой**.

При ошибке прочитайте сообщение, исправьте файл и используйте **Загрузить заново**. Повторная загрузка создаёт новый датасет. Изменение файла на вашем компьютере не меняет ранее загруженную копию.

### Подключение базы

Попросите администратора базы подготовить строку подключения с правами только на чтение и убедиться, что база доступна из DjedAI.

1. Откройте **Источники → Подключить БД**.
2. Выберите **PostgreSQL** или **ClickHouse**.
3. Вставьте выданную **Строку подключения (DSN)**.
4. Нажмите **Проверить соединение**.
5. Отметьте нужные таблицы. Если ничего не выбрано, подключаются все доступные таблицы.
6. Нажмите **Подключить** и дождитесь готовности датасета.

Проверка соединения сама по себе не добавляет источник: после неё нужно нажать **Подключить**. Если вы изменили адрес или тип базы, выполните проверку ещё раз. Строка подключения может содержать пароль — не вставляйте её в аналитический чат и не публикуйте на снимках экрана.

### Когда обновляются данные

| Источник | Как работать с изменениями |
| --- | --- |
| CSV | Для изменённого содержимого загрузите новый файл |
| ClickHouse | DjedAI анализирует сохранённый снимок. Чтобы обновить его, нажмите **Перепрофилировать** в каталоге |
| PostgreSQL | Новый расчёт читает базу заново. Если изменилась структура или устарело описание, обновите каталог через **Перепрофилировать** |

Старый ответ в истории остаётся прежним. Чтобы получить актуальное число, задайте новый вопрос или обновите данные дашборда.

## Проверка каталога

Каталог показывает, как DjedAI распознал ваши данные. Откройте его после загрузки и проверьте:

- все ли нужные таблицы и колонки присутствуют;
- стали ли суммы числами, а даты — датами;
- есть ли пропуски и предупреждения о нераспознанных значениях;
- соответствуют ли найденные связи смыслу ваших таблиц.

**Исходное имя** — заголовок из источника. **В системе** — имя, под которым колонка используется в расчётах. В вопросе можно явно назвать нужную колонку, чтобы избежать неоднозначности.

Описания таблиц и колонок помогают ориентироваться, но могут быть неточными. Например, название «сумма» само по себе не определяет валюту или правила учёта возвратов. Такие условия указывайте в вопросе.

В **Журнале обработки данных** видны предупреждения о преобразованиях. Если часть чисел не распозналась, это может повлиять на итог. Ошибки файла исправляйте в исходных данных и загружайте файл заново. Редактирования типов и связей в каталоге пока нет.

**Перепрофилировать** обновляет каталог из сохранённого источника. Во время обновления прежняя версия остаётся доступной; при неудаче появляется сообщение об ошибке. Для CSV эта кнопка повторно обрабатывает уже загруженные файлы, а не читает изменённый файл с вашего компьютера.

## Вопросы и продолжение разговора

Выберите готовый датасет и откройте **Чат**. Введите вопрос в поле **Вопрос к данным**, затем нажмите **Отправить** или Enter.

В вопросе полезно назвать показатель, период, группировку и исключения. Например:

> Посчитай число заказов по месяцам за 2025 год. Используй дату создания заказа, отменённые заказы исключи. Покажи таблицу и линейный график.

Если в данных нет нужного признака, система не сможет надёжно восстановить его по названию. Уточните реальные колонки и смысл показателя. Особенно это важно для слов «выручка», «активный клиент», «прибыль» и для валюты.

### Уточнение и следующий вопрос

При неоднозначности DjedAI может предложить варианты. Нажмите подходящий или ответьте своим текстом. Если уточняется определение показателя, прочитайте формулу и условия перед подтверждением: они могут использоваться в следующих расчётах.

Продолжать можно короткими фразами: «А теперь по регионам», «Оставь только North», «Покажи это таблицей». Для важного расчёта повторите ключевые условия, особенно после длинного разговора.

**Новый чат** начинает отдельный разговор. Сохранённые чаты активного датасета доступны в истории слева.

### Ожидание и остановка

Пока вопрос выполняется, интерфейс показывает текущий этап. **Остановить** прекращает ожидание и отправляет запрос на остановку обработки; завершение может занять некоторое время.

После обрыва связи или обновления страницы сначала откройте историю и посмотрите исход вопроса. Прежний вопрос автоматически не отправляется заново. Если нужен новый запуск, используйте **Повторить вопрос** либо отправьте сообщение ещё раз.

## Как проверить ответ

Под ответом раскройте **Результат расчёта …** и **Как посчитано**. Проверьте выбранные данные, условия, время расчёта и предупреждения. Если доступен запрос SQL, его можно передать аналитику для дополнительной проверки; для повседневной работы читать SQL необязательно.

Предпросмотр результата показывает только первые 20 строк. Для общей суммы попросите посчитать сумму по всему набору, а не складывайте показанные строки вручную. Предупреждение об ограниченном результате означает, что доступна лишь часть данных.

Некоторые значения отображаются округлённо. Денежный формат сейчас использует знак ₽; сам знак не подтверждает валюту исходных данных. Для проверки дробных чисел попросите таблицу с обычным числовым форматом и явно укажите нужную точность.

Ссылки **Метаданные JSON** и **Данные JSON** в текущей версии могут открывать ошибку доступа. Для просмотра используйте встроенную карточку. Если нужна выгрузка для дальнейшей работы, обратитесь к человеку, который сопровождает установку. Отдельной кнопки экспорта CSV или изображения графика пока нет.

Перед использованием важного результата сопоставьте его с известным контрольным числом. Корреляция показывает связь, но не доказывает причину. Прогноз — оценка, зависящая от данных и метода. Пустой результат или ошибка не означают нулевое значение показателя.

## Графики и таблицы

Укажите нужный вид прямо в вопросе: «столбчатая диаграмма по регионам», «линейный график по месяцам», «таблица» или «один показатель с общей суммой».

DjedAI поддерживает линии, области, столбцы, круговые диаграммы, диаграммы рассеяния, гистограммы, тепловые карты, ящики с усами, таблицы и карточки показателей. Доступный вид зависит от полученных данных.

Наведите указатель на график, чтобы увидеть значения. У некоторых графиков легенда позволяет скрывать и показывать ряды. Чтобы изменить представление, напишите следующее сообщение: отдельного редактора осей и палитры пока нет.

Если нужен топ по всему набору, сформулируйте это явно: «Найди 10 регионов с наибольшей суммой по всему датасету». Видимые категории графика могут быть ограничены.

**Нет данных для графика** означает пустой результат. Если отсутствуют подходящие числовые значения или поля несовместимы, измените вопрос либо попросите таблицу. Повтор загрузки графика получает уже сохранённый результат; для нового расчёта нужен новый вопрос.

## Дашборды

Дашборд — сохранённая подборка показателей и графиков одного датасета. Для создания отправьте запрос в чат, например:

> Собери дашборд «Проверка CSV» из трёх виджетов: число строк, сумма amount и сумма amount по region. Валюта не указана.

После выполнения нажмите **Открыть на экране дашбордов**. Позже его можно выбрать по названию в разделе **Дашборды**. Для нового дашборда вернитесь в чат и опишите следующую подборку.

Можно сохранять и отдельные графики ответа. Нажмите **В дашборд** в заголовке графика, выберите существующий дашборд этого датасета либо **Новый дашборд**. После сохранения появится уведомление со ссылкой. Название новой подборки берётся из заголовка графика. Если список или сохранение завершились ошибкой, прочитайте сообщение и повторите действие через то же меню.

Открытие дашборда показывает сохранённые значения. **Обновить данные** заново рассчитывает все его виджеты. Для обновления снимка ClickHouse сначала выполните **Перепрофилировать** в каталоге. CSV продолжает использовать загруженную копию, PostgreSQL может вернуть новые значения.

Виджет раскрывается кнопкой **Как посчитано**; **Скрыть расчёт** возвращает график. **Удалить** убирает выбранный виджет. Переименование, удаление всего дашборда и перемещение виджетов мышью пока недоступны.

Если часть виджетов завершилась с ошибкой, прочитайте их сообщения и сравните время обновления остальных. **Повторить** в ошибочном виджете пересчитывает весь дашборд. Отсутствующее число не следует считать нулём.

## Выбор модели

В **Настройках** выберите доступную модель и нажмите **Сохранить**. Изменение применяется к следующим вопросам; сохранённые ответы остаются прежними.

Настройки модели **общие для всей установки**. Если DjedAI используют несколько человек, согласуйте изменения с администратором. Когда нужной модели нет в списке или соединение не работает, обратитесь к нему.

В некоторых установках доступны поля **Адрес API** и **Ключ API**. Используйте только параметры, согласованные с ответственным за установку. **Проверить** проверяет доступность модели, а **Сохранить** применяет изменения — это разные действия. Пустое поле ключа не означает, что сохранённый ключ отсутствует.

Для ответа модель может получать вопрос, часть истории, описание данных и значения текущего расчёта. Состав передачи зависит от настройки установки. До загрузки рабочих данных уточните у администратора, какая модель используется и какие данные разрешено анализировать.

## Если возникла проблема

| Ситуация | Что сделать |
| --- | --- |
| Датасет не выбран | Выберите готовый набор сверху или добавьте источник |
| Обработка ещё идёт | Откройте **Следить за обработкой** и дождитесь результата |
| Прервался показ прогресса | Нажмите **Повторить получение прогресса** |
| Файл не принимается | Проверьте формат; при сообщении о размере уменьшите файл или обратитесь к администратору |
| База недоступна | Повторите **Проверить соединение**; уточните параметры у администратора базы |
| Сессия истекла | Войдите снова и откройте прежний чат |
| Модель недоступна | Сообщите администратору текст ошибки |
| Вопрос завершился по времени | Прочитайте сохранённый исход; при необходимости повторите вопрос |
| Очередь переполнена | Дождитесь завершения текущей работы и повторите позже |
| Каталог несовместим с источником | Выполните **Перепрофилировать**; при повторной ошибке обратитесь к администратору |
| Число выглядит неверным | Проверьте набор, фильтры, единицы и предупреждения; сравните с контрольным расчётом |
| Ошибка одного виджета | Прочитайте сообщение; учитывайте, что **Повторить** обновляет весь дашборд |

При обращении за помощью укажите действие, время, текст ошибки и идентификатор запроса, если он показан. Пароль, ключ модели и строку подключения прикладывать не нужно.
