# Документация

- [repository-guide.md](repository-guide.md) — назначение всех каталогов и служебных файлов, необходимость каждого из них и место для будущих настроек.
- [ci-cd-plan.md](ci-cd-plan.md) — предлагаемый порядок внедрения CI, интеграционных прогонов, оценки модели и выпуска для локального запуска.
- [specification.md](specification.md) — исходная техническая спецификация проекта, перенесённая без изменений содержания.
- [issues-plan.md](issues-plan.md) — сохранённый исходный план создания issues с историческим статусом публикации.
- [source/ai-native-bi-plan.html](source/ai-native-bi-plan.html) — исходная визуальная схема плана.
- [source/case-2-ai-native-bi.docx](source/case-2-ai-native-bi.docx) — исходное описание кейса организаторов.

Спецификация содержит открытые решения и исходную ролевую модель. Согласованные позднее условия — отсутствие отдельной PM-роли, регистрация и личные данные, границы ранних этапов — описаны в плане и опубликованных issues. Это не повод выбирать открытые технические решения самостоятельно.

План сохранён как исходный документ: его строки «публикация не выполнялась» и «ожидание согласования» относятся к моменту подготовки. Сейчас issues уже опубликованы и их оформление обновлено. Текущие критерии и статус выполнения смотрим в [GitHub Issues](https://github.com/Polozhentsev-Ivan/DjedAI/issues); правила работы — в [CONTRIBUTING.md](../CONTRIBUTING.md).

Изменения архитектуры и общих контрактов согласуем с затронутыми участниками, затем обновляем соответствующий документ и issue. README каталогов уточняют расположение кода и не создают нового функционального объёма.
