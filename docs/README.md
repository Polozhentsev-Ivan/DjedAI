# Документация DjedAI

Материалы к сдаче 31.10: [Architecture.md](../Architecture.md),
[Criteria.md](../Criteria.md), [TestCases.md](../TestCases.md).
Они отдельно фиксируют подтверждённые результаты и незавершённые проверки.

Выберите руководство по своей задаче. Каждое рассчитано на отдельного читателя и имеет собственное оглавление.

| Руководство | Для кого | Что внутри |
| --- | --- | --- |
| [Пользователю](user/README.md) | Для работы с данными в браузере | Загрузка данных, каталог, вопросы, проверка ответа, графики и дашборды |
| [Разработчику](developer/README.md) | Для изучения и изменения проекта | Архитектура, решения, компоненты, API, окружение, GitHub/CI и тестирование |
| [Администратору](administrator/README.md) | Для установки и сопровождения | Сборка, конфигурация, запуск, диагностика, обновление и восстановление |

Для первого знакомства с приложением откройте [пользовательский пример](user/user-guide.md#первый-анализ-на-небольшом-примере). Для знакомства с кодом — [архитектуру](developer/architecture.md).
