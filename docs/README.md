Спецификация содержит открытые решения и исходную ролевую модель. Согласованные позднее условия — отсутствие отдельной PM-роли, регистрация и личные данные, границы ранних этапов — описаны в плане и опубликованных issues. Выбор UI утверждён пользователем: отдельный browser frontend на React + TypeScript в `frontend/`, Vite/npm, генерируемые типы из API-схем Python backend; это решение больше не относится к открытым вопросам.

План подготовлен 15 октября, 19 октября описания 23 связанных issues обновлены под React + TypeScript. Текущие критерии и статус выполнения смотрим в [GitHub Issues](https://github.com/Polozhentsev-Ivan/DjedAI/issues); правила работы — в [CONTRIBUTING.md](../CONTRIBUTING.md).

Исходные DOCX и HTML в `source/` сохраняются как материалы кейса и раннего плана; актуальные решения по UI описаны в спецификации, плане и опубликованных issues. Это обновление документов не подтверждает готовность самого frontend-приложения.

Изменения архитектуры и общих контрактов согласуем с затронутыми участниками, затем обновляем соответствующий документ и issue. README каталогов уточняют расположение кода и не создают нового функционального объёма.
