# Промпты

Версионируемые тексты промптов и примеры для понимания вопроса, плана, ответа и других предусмотренных этапов агента.

Здесь хранится текст, а код его загрузки и вызова модели — в `src/djedai/agent/`. Не добавляем личные данные, секреты и реальные пользовательские диалоги. Пока промпты не реализованы, фиктивные рабочие файлы не создаём.

- `describe_table.md`, `describe_dataset.md` — описания колонок, таблиц и `summary` каталога (B1-6, `djedai.data.descriptions`). Вход — JSON в сообщении пользователя, ответ — JSON по схеме, текст по-русски. Черновик, согласуется с MLE. После правки увеличиваем `PROMPT_VERSION` в `descriptions.py`: от него зависит ключ кэша описаний.
