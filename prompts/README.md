# Промпты

Версионируемые тексты промптов и примеры для понимания вопроса, плана, ответа и других предусмотренных этапов агента.

Здесь хранится текст, а код его загрузки и вызова модели — в `src/djedai/agent/`. Не добавляем личные данные, секреты и реальные пользовательские диалоги. Пока промпты не реализованы, фиктивные рабочие файлы не создаём.

- `describe_table.md`, `describe_dataset.md` — описания колонок, таблиц и `summary` каталога (B1-6, `djedai.data.descriptions`). Вход — JSON в сообщении пользователя, ответ — JSON по схеме, текст по-русски. Черновик, согласуется с MLE. Текст промпта входит в ключ кэша описаний: после правки описания пересчитываются автоматически.
- В `understand.md` и `plan.md` агенту сказано, что описания каталога сгенерированы моделью и служат подсказкой, а типы, статистика, ключи и связи посчитаны по данным.
- Бизнес-метрики (B2-9, #166): `understand.md` уточняет метрику без подтверждённого определения и прикладывает к вариантам кандидатов `metric_candidates`; `plan.md` считает подтверждённые метрики через `compute_metric`; `compose.md` называет версию определения и ограничения из факта `metric_definition`.
- `dashboard.md` — планирование дашборда (B3-8, #78): 3–8 независимо перевыполняемых виджетов, 1–5 шагов на виджет, общий бюджет `DASHBOARD_MAX_TOOL_CALLS`, зависимости через `source_step_id` и `source_result`, график по фактическим колонкам выходного шага.
