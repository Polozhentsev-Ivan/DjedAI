# Инфраструктура

Будущие Dockerfile, вспомогательные конфигурации локального запуска и демо-источников. Сюда относится инфраструктура сервисов, а не Python-бизнес-логика.

Итоговый `compose.yaml` планируется в корне репозитория, чтобы запускать проект оттуда; конкретную конфигурацию создаём в инфраструктурных задачах после выбора версий и сервисов. Сейчас исполняемых файлов запуска нет.

Секреты и содержимое постоянных томов в Git не добавляются. Модель и демо-БД подключаются по согласованной архитектуре и этапам.
