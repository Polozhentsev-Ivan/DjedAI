# Инфраструктура

Будущие Dockerfile, вспомогательные конфигурации локального запуска и демо-источников. Сюда относится инфраструктура сервисов, а не Python-бизнес-логика.

Итоговый `compose.yaml` планируется в корне репозитория. Backend — Python/FastAPI; frontend — отдельная сборка React + TypeScript из [frontend/](../frontend/README.md), в production статические файлы обслуживает nginx. API/SSE проксируются на backend с единым origin, поддержкой длительного streaming-соединения и согласованной передачей сессии. Dev proxy Vite и публичная базовая URL API реализуются в B4-1 / #83.

Конфигурации запуска, точные версии образов и Compose создаются в инфраструктурных задачах. Сейчас исполняемых файлов контейнерного запуска нет. Python UI-сервис и Streamlit/Taipy не требуются.

Секреты и содержимое постоянных томов в Git не добавляются. Настройки `VITE_*` публичны и подставляются при сборке frontend; серверные секреты и адреса внутренних сервисов в браузерную сборку не передаются. Для dev-запросов с другого origin backend должен читать явный CORS allowlist; шаблон переменной в `.env.example` ещё не реализует загрузчик или сетевую политику. Модель и демо-БД подключаются по согласованной архитектуре и этапам.
