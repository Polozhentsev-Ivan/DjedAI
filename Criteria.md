### Условия текущих прогонов E9–E11

Полные исходные CSV сверены по размеру, SHA-256 и Git blob SHA-1 с manifests
ревизии данных `716fbbcdc3dfa2a63dba1cf835fcc780c5e91a1d`. Golden использует
`08_Фоновые_задания.csv`, 500 000 строк. Q1/Q2/Q4/Q5/Q6 взяты из Downloads;
для Q3 использована полная кэш-копия, поскольку в Downloads остался `.crdownload`.
Вопросы организаторов сверены с `questions.txt`.

Профиль: внешний DeepInfra `Qwen/Qwen3.6-27B`, таймаут модели и хода 120 с,
один retry, контекст 8192, выход модели 2048 токена, dashboard-плана 4096.
Reasoning: `none` для understand/visualize/compose/verify, `provider_default`
для plan. Две параллельные очереди, по одному последовательному worker в каждой.
SHA, версии зависимостей, источники, интервалы и хеши отчётов — в
[provenance.json](eval/reports/final-20261031-a32c15c/provenance.json).

Использован настоящий граф приложения с моделью и SQL. Время в отчётах —
`duration_seconds`, без загрузки CSV. Браузер, видео, перезапуск production-хранилища
и изоляция владельцев не проверялись. `correct` в ручной оценке означает корректность
сохранённого ответа, вычислений и спецификаций в этом объёме, а не полную приёмку UI.
`partial` — неполнота объяснения или несоответствие требуемой спецификации;
`incorrect` — неверный результат либо подтверждённый отказ выполнить запрос;
`not_evaluated` — недостаточно ответа для оценки из-за ошибки выполнения, блокировки
или пропуска. Автоматические `needs_review` в исходном JSON не переписаны вручную:
ручная оценка хранится отдельно.

PowerShell-обёртка исходного golden вернула код 1 с записью `NativeCommandError`
на предупреждениях LangGraph о десериализации checkpoint. Независимый exit code
Python не сохранён; успех процесса не заявляется. При этом JSON имеет
`status=completed`, `finished_at`, точный SHA и все 53 исхода без pending.
Наблюдение сохранено в [протоколе процесса](eval/reports/final-20261031-a32c15c/golden-process-observation.json).

### Подтверждённые проблемы приложения

- `s4_service_top5_bar_01`: ChartSpec `orientation=vertical` при запросе
  горизонтальных столбцов. `s6_switch_monthly_chart_01`: `x.kind=category`
  вместо временной оси. Значения и контекст сохранены, представление не соответствует запросу.

  пяти строк, хотя frontend принимает одну. Вызов настоящей функции на сохранённых
  спецификациях воспроизвёл три ошибки; [результат проверки](eval/reports/final-20261031-a32c15c/chart-compatibility.json).
  Это проверка совместимости данных, не браузерная запись.
- `s6_refresh_previous_dashboard_01`: understanding вернул `intent=dashboard`,
  `dashboard_id=null`; [маршрутизация графа](src/djedai/agent/graph.py) создала
  `d_eval_9929a48dd1ce` вместо прежнего `d_eval_37401ddab9ab`, изменились ID виджетов.
  Запрос обновить ту же панель не выполнен.
- `s10_growth10_01`: understand классифицировал допустимый запрос как `invalid`,
  потребовал финансовые данные и отказался от прогноза. SQL не выполнялся,
  запрошенные ряды baseline и baseline × 1,1 не выданы.
- Q6-r1 организаторов: все 18 групп SQL верны, но
  [проверка чисел](src/djedai/agent/verification.py) отвергла дополнительный общий

## Одиннадцать технических критериев

Формулировки T9–T10 сохраняют исходное требование локальности. Внутреннее
[решение команды о внешнем inference](docs/decisions/47-contracts-and-runtime.md)
не означает согласия организаторов с таким исключением.

| ID | Требование | Статус | Результат, свидетельство и граница |
| --- | --- | --- | --- |
| T1 | Прямое подключение к PostgreSQL или ClickHouse без предварительной обработки | Частично | Историческое E2; [адаптеры](docs/developer/data-and-catalog.md) реализованы. В E9–E11 подключения к этим БД не запускались. |
| T2 | Приём сырых CSV, преобразования внутри платформы | Частично | E9–E11: шесть полных pinned CSV загружены через runtime; golden — полный файл из 500 000 строк. Загрузка всех девяти файлов через браузер на этом SHA не проверена. |
| T3 | Понятное описание структуры и содержимого | Частично | E10: числовые ответы сценариев 1–3 верны, ряд обязательных объяснений отсутствует или не подтверждён. Ручные оценки приложены. |
| T4 | Визуализация в диалоге, автоматический выбор и смена вида | Частично | E10 выявил несовместимые KPI, неверную ориентацию и тип оси. Сквозная browser-приёмка не выполнена; [#175](https://github.com/Polozhentsev-Ivan/DjedAI/issues/175), [#245](https://github.com/Polozhentsev-Ivan/DjedAI/issues/245). |
| T5 | Автоматический дашборд, доступный повторно | Частично | E10 подтвердил часть создания и пересчёта в eval, но refresh создал новую панель. Production persistence/restart/owner isolation не проверены, #175 не закрывается. |
| T6 | Ответы и графики понятны бизнес-пользователю | Частично | Независимая ручная оценка E9–E11 выполнена; выявлены неполные и неподтверждённые пояснения. Два UX-прогона [#91](https://github.com/Polozhentsev-Ivan/DjedAI/issues/91) с бизнес-пользователями не выполнены. |
| T7 | Память на уровне диалога | Частично | E10: 1 correct, 2 partial, 1 incorrect, 1 blocked в сценарии 6. Контекстные данные доступны, но представление и идентичность панели нарушены; [#246](https://github.com/Polozhentsev-Ivan/DjedAI/issues/246). |
| T8 | Помощь с некорректными/неудобными вопросами | Частично | E10: 9 краевых ответов корректны; пустой ввод skipped, отдельно API возвращает 422. Browser-граница не проверена; [#226](https://github.com/Polozhentsev-Ivan/DjedAI/issues/226). |
| T9 | Локальный запуск без зависимости от внешних закрытых систем | Частично | [Backend/UI/storage локальные](docs/administrator/local-build.md), но E9–E11 используют внешний DeepInfra. Локальная модель и чистая установка не проверены; [#50](https://github.com/Polozhentsev-Ivan/DjedAI/issues/50). |
| T10 | Отсутствие облачных решений внутри; open source с подходящей лицензией | Не проверено | Проект распространяется под [MIT](LICENSE); [проверка компонентов](docs/developer/licenses.md) фиксирует версии, лицензионные метаданные, бинарные исключения NumPy/SciPy и Apache-2.0 upstream-весов Qwen. Репозиторий пока приватный, проверенный inference облачный. Точные веса сервиса, состав образов и обязательства готовой поставки не подтверждены; итоговый аудит #50 не завершён. |
| T11 | Интернет только к определённым доменам/API, без поисковых движков | Частично | В описанном runtime нет веб-поиска; [политика](docs/decisions/173-data-transfer-policy.md) ограничивает контекст модели. `ALLOWED_OUTBOUND_HOSTS` не обеспечивает сетевую фильтрацию; allowlist сдаваемого окружения не проверен. |

## Ограничения на момент сдачи

- Подтверждены дефекты ответов, проверки чисел, графиков и refresh.
- Часть ответов прервана инфраструктурой. Исходы всех попыток сохранены;
  E11 не заменяет полный E10 и не делает исходный запуск успешным.
- Три последовательных полноценных успеха каждого вопроса организаторов
  в пределах 120 с не подтверждены. Состояние видео и доступа указано в [TestCases.md](TestCases.md).
- Production browser/restart/refresh, чистая установка, полный лицензионный аудит,
  модель организаторов и сетевые ограничения в этом прогоне не подтверждены.

[#243](https://github.com/Polozhentsev-Ivan/DjedAI/issues/243) и
[#244](https://github.com/Polozhentsev-Ivan/DjedAI/issues/244) этим отчётом не закрываются.
Финальный прогон завершён с указанными результатами; выполнение всех критериев
этих задач, доступ эксперта, видео и отправка материалов им не подтверждаются.
