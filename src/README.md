# Исходный код Python

Здесь размещается собственный серверный Python-код приложения, внутри `djedai/`. Окружение описано в корневых `pyproject.toml` и `uv.lock`; Python-тесты находятся в `tests/`.

Браузерный React + TypeScript интерфейс размещается отдельно в [frontend/](../frontend/README.md) и взаимодействует с backend через HTTP API/SSE.
