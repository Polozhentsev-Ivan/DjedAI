# Backend

FastAPI, API и SSE, хранение метаданных приложения и миграции, чаты, реестр результатов, дашборды, пользователи, сессии и проверки доступа.

Загрузка и профилирование вызываются через интерфейс `data/`, расчёты — через `analytics/`, работа агента — через `agent/`. Общие модели берём из `contracts/`. Размещение авторизации здесь обозначает место серверного кода, а не назначает исполнителя AUTH-задач.

Подкаталоги API, хранения и авторизации добавляются по мере реализации; готовых эндпоинтов и схем БД пока нет.
