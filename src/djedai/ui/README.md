# Пользовательский интерфейс

Источники данных, каталог, чат, рендер графиков, дашборды, регистрация и вход, состояния ожидания/ошибки и русские форматы.

Выбор Streamlit/Taipy остаётся согласуемым решением. UI использует API и общие форматы, а данные графика получает по `result_id`. Загрузка в DuckDB и аналитические вычисления не реализуются повторно на экранах.
