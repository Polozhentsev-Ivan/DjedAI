# Компоненты приложения

- `contracts/` — общие модели обмена.
- `data/` — приём данных, каталог и источники.
- `analytics/` — расчёты и безопасный SQL.
- `agent/` — граф, состояние и логика агента.
- `backend/` — API, хранение и авторизация.
- `ui/` — экраны и визуализации.

Границы следуют спецификации и issues. Общие схемы согласуются между потребителями; конкретные классы и интерфейсы создаются в соответствующих задачах.
