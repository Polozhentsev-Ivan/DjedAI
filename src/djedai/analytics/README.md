# Аналитика

Реестр инструментов, безопасный `run_sql` и фиксированные аналитические функции: обзор, частоты, временные агрегаты, качество данных и расширенные расчёты из issues.

Инструменты возвращают общий `ToolResult` и работают в разрешённом контексте данных. Загрузка источников относится к `data/`, планирование вызовов моделью — к `agent/`. Вычисления проверяются независимыми эталонами.

В HTTP-ходе чата сервер передаёт `execute_tool(..., connection=..., allowed_tables=...)`:
разрешены только типизированные представления из каталога выбранного датасета.
`describe_dataset` показывает этот список; `describe_column` и `value_counts` проверяют
таблицу, а SQL и вложенные фильтры проверяются по AST с учётом JOIN, CTE и подзапросов.
Прямое обращение к подключённому PostgreSQL, сырым таблицам, системным каталогам,
табличным функциям, файловым/сетевым функциям и произвольным SQL-макросам запрещено.
Обычные распознаваемые SQLGlot агрегатные и скалярные функции доступны. Драйверные ошибки
в этом режиме не раскрывают адреса источников и внутренние пути.

`source_result_id` пока отклоняется явно: повторное вычисление поверх сохранённого
результата требует отдельного контекста владения и не подменяется запросом к датасету.
Вызовы Python без `allowed_tables` предназначены для доверенных адаптеров и тестовых
фикстур; HTTP-маршрут всегда задаёт область доступа на сервере.
