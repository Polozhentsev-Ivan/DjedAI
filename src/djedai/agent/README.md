# Агент

Клиент модели, граф LangGraph, состояние, понимание вопроса и уточнения, планирование, выполнение, проверка чисел, память, выбор графиков и ветка дашборда.

Тексты промптов храним в корневом `prompts/`. Агент вызывает инструменты аналитики и использует результаты вычислений; HTTP-транспорт и постоянное хранение относятся к `backend/`.
