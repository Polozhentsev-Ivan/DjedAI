# Агент

Клиент модели, граф LangGraph, состояние, понимание вопроса и уточнения, планирование, выполнение, проверка чисел, память, выбор графиков и ветка дашборда.

Тексты промптов храним в корневом `prompts/`. Агент вызывает инструменты аналитики и использует результаты вычислений; HTTP-транспорт и постоянное хранение относятся к `backend/`.

## Проверки вопроса до модели

`guards.py` решает явные случаи кодом, поэтому результат не зависит от силы модели.
Понимание вопроса вызывается только если проверки ничего не нашли. Модель получает
те же правила в `prompts/understand.md` для случаев, которые код не распознаёт.

- Перепутанный период: `с … по …`, `от … до …`, `между … и …`, диапазон через дефис
  или тире. Ответ — `invalid` с уточнением, даты не переставляются. Тот же поиск идёт
  по `resolved_question` модели, например для «за тот же период».
- Команды записи и обход режима только чтения: `invalid` и текстовый отказ с причиной.
- Чтение внешних ссылок и локальных файлов: `invalid` и текстовый отказ.
- Удаление данных обычными словами («удали из таблицы»): `invalid` с безопасными
  вариантами.
- Денежный показатель, когда в каталоге и подтверждённых метриках нет признаков денег:
  `invalid` с объяснением. Показатель, названный исключением или заменой, не считается.

Границы проверок:

- Срабатывают только явные формы. Упоминание SQL или удаления в вопросе не приводит
  к отказу. Переформулированный запрос может пройти к модели; защита чтения на
  уровне `run_sql` от этого не зависит.
- Цитата после слова условия («содержащие текст «…»») считается значением фильтра и
  не проверяется. Отказ остаётся для команды вне цитаты и для цитаты после глагола
  запуска в той же фразе.
- Форма «прибыли» совпадает с глаголом, поэтому код считает её показателем только рядом
  с определяющим словом («рост прибыли»). Иначе вопрос решает модель.
- Период не проверяется для кварталов и относительных дат. Разные месяцы без годов не
  сравниваются из-за перехода через Новый год, а `дд/мм` и `мм/дд` дают срабатывание,
  только если период перепутан при обоих прочтениях. `между` пропускается для годов,
  месяцев и вопросов со словом сравнения.
- Признаки денег — словарь слов, а не смысл данных. Колонка с нетипичным именем без
  описания не будет распознана как денежная. Лишнее совпадение только отключает
  проверку и передаёт вопрос модели.
- Неоднозначные показатели, например единицу подсчёта в проценте, код не определяет:
  это остаётся правилом промпта.

## Ветка дашборда

Запрос с интентом `dashboard` идёт мимо обычного плана на пять шагов:
`plan_dashboard → execute_dashboard → save_dashboard`. `dashboard.py` проверяет
лимиты ветки (3–8 виджетов, 1–5 шагов на виджет, общий бюджет
`DASHBOARD_MAX_TOOL_CALLS`, отдельный потолок вывода
`DASHBOARD_MAX_OUTPUT_TOKENS`), нормализует `step_id`, собирает `tool_call` или
`WidgetRecipe` с зависимостями `source_step_id`, чинит график по фактическим
колонкам и формирует превью. Зависимый шаг получает данные родителя как
`source_result`; временные `source_result_id` в рецепт не сохраняются. Если хотя бы
один виджет не посчитался, план повторяется один раз, после чего сохраняется
частичный дашборд с явными ошибками. Подробности —
[docs/decisions/78](../../../docs/decisions/78-dashboard-branch.md).

## Быстрый маршрут

Точный вопрос о числе строк явной таблицы и запрос её структуры обслуживаются
без вызова модели: `load_ctx → fast_route`, затем `execute → fast_compose →
cite_metrics` для COUNT или `fast_compose` для структуры. COUNT выполняется
штатным `run_sql` с `allowed_tables` текущего owner/dataset и сохраняется как
обычный `ToolResult` с `result_id`. Структура берётся из текущего каталога, а не
из устаревшего `row_count`. Фильтры, JOIN, группировки, отрицания, ссылки на
прошлый ответ и неоднозначный выбор таблицы остаются на общем маршруте.
Точный список фраз и условий — `docs/agent-fast-path.md`.

## Передача данных модели

`data_policy.py` — единственный контракт того, какой контекст попадает во внешнюю
модель. `DataTransferPolicy` создаётся вместе с `BIModelClient` и передаётся всем
узлам графа и описаниям каталога; `generate_typed_response()` выполняет итоговую
проверку перед сетевым вызовом. Отдельный клиент в обход политики добавлять нельзя.

- `ALLOW_DATA_SHARING=false` (по умолчанию) — метаданные, вопрос и история, факты,
  агрегаты и значения текущего результата; без выборок каталога и сырых строк
  прошлых ходов.
- `ALLOW_DATA_SHARING=true` — дополнительно выборки каталога и строки истории для
  доверенного endpoint.
- Секреты, DSN, пароли и токены не передаются никогда; ошибки модели и диагностика
  не содержат prompt, ответа провайдера и строк данных.

Подробности, примеры payload по стадиям и ограничения —
[docs/decisions/173](../../../docs/decisions/173-data-transfer-policy.md).
